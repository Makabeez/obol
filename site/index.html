Which paid APIs actually deliver?

Obol is an agent with a USDC budget. It pays x402 services per call on Arc mainnet, scores what comes back, stops paying the ones that fail, and writes each verdict to a public registry any other agent can read before it pays.

How a verdict is made

Pay

The agent pays the seller's HTTP 402 challenge in USDC on Arc, by EIP-3009 transfer or through Circle Gateway. It only pays allowlisted sellers at pinned addresses, under per-call and lifetime caps.

Score

It checks the response: did it arrive, is it complete, how fast, and for chain data, how far behind the live Arc head it is. Stale or empty data scores low.

Record

A Thompson-sampling allocator moves spend toward sellers that deliver value per USDC. Sellers that keep failing are retired on-chain, with the evidence attached.
